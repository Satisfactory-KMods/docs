## Production Modeler

Draw a factory the way you build it and let the numbers follow, or let the
modeler plan a chain from "I want X per minute" and edit what it gives you.
Covers the canvas, special buildings, automatic planning and saving.

[Read the Production Modeler guide](/production-modeler)

:::tip
Press **Ctrl+K** (or **/**) anywhere in the docs to search. Use the **arrow
keys** to move between results and **Enter** to open one.
:::

## KDataForge

Reference documentation for the KDataForge Satisfactory mod, a YAML-driven,
zero-code runtime content editing framework. Covers its architecture, full
YAML schema, module structure, public API, worked examples for every document
type, and task-oriented tutorials.

[Read the KDataForge docs](/kdataforge)
