The planner's shortcuts dialog contains the same keyboard controls listed here.
See [Canvas basics](/production-planner/canvas) for the gestures and block
controls used with them.

:::note
On macOS, use **Cmd** wherever these tables say **Ctrl**.
:::

## Editing

| Shortcut                            | Action                |
| ------------------------------------ | --------------------- |
| **Ctrl + Z**                        | Undo                  |
| **Ctrl + Y** / **Ctrl + Shift + Z** | Redo                  |
| **Delete** / **Backspace**          | Delete selected block |
| **Ctrl + C**                        | Copy selected blocks  |
| **Ctrl + V**                        | Paste blocks          |

## Navigation

| Shortcut         | Action                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------- |
| **Ctrl + F**    | Search the canvas                                                                                              |
| **1** to **9**  | Switch [sidebar panel](/production-planner/panels) (Build Progress, Outputs, Extractors, Byproducts, Stats, Balance, Snapshots, Summary, Settings) |
| Scroll          | Zoom in / out                                                                                                   |
| Drag background | Pan the canvas                                                                                                  |
