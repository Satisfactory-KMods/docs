Work faster with the keyboard. All shortcuts are also listed in the planner's
shortcuts dialog.

:::note
On macOS, use **Cmd** wherever these tables say **Ctrl**.
:::

## Editing

| Shortcut                            | Action                |
| ------------------------------------ | --------------------- |
| **Ctrl + Z**                        | Undo                  |
| **Ctrl + Y** / **Ctrl + Shift + Z** | Redo                  |
| **Delete** / **Backspace**          | Delete selected block |
| **Ctrl + C**                        | Copy selected blocks  |
| **Ctrl + V**                        | Paste blocks          |

## Navigation

| Shortcut         | Action                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------- |
| **Ctrl + F**    | Search the canvas                                                                                              |
| **1** to **9**  | Switch sidebar panel (Build Progress, Outputs, Extractors, Byproducts, Stats, Balance, Snapshots, Summary, Settings) |
| Scroll          | Zoom in / out                                                                                                   |
| Drag background | Pan the canvas                                                                                                  |
