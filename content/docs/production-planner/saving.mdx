Your work is kept safe and easy to share.

## Cloud & local saving

Signed-in plans save to the **cloud** automatically as you work. You can also
keep plans **locally** in your browser. Toggle cloud saving any time in
**Settings**.

## Snapshots

Take a labelled **snapshot** before a big change so you can jump back to it
later. Cloud saving must be on to use snapshots.

:::caution
Snapshots need cloud saving turned on. If a plan is local-only, taking a
snapshot won't be available switch cloud saving on in **Settings** first.
:::

## Import & export

Download a plan as a `.pp.json` file to back it up or share it; import one the
same way. Older files are upgraded automatically on load.

## Sharing

Make a plan **public** to share a view-only link. Anyone with the link can
look but not edit.

## Comparing plans

Put two plans side by side to compare power, buildings, inputs, and outputs.
This is handy for choosing between approaches. Either side can compare a
saved **snapshot** instead of the live plan, so you can see exactly what
changed since you took it.
