Your work is kept safe and easy to share.

## Planner home

The planner home separates the current browser-local plan from cloud plans.
Responsive plan cards show their main outputs and status at a glance; open a
card to continue, or use its action menu to export, clone, change visibility,
copy a link, or delete it. You can also import a plan or start from a community
template without opening an existing session first.

## Cloud & local saving

Signed-in plans save to the **cloud** automatically as you work. You can also
keep plans **locally** in your browser. Toggle cloud saving any time in
**Settings**.

## Snapshots

Take a labelled **snapshot** before a big change so you can jump back to it
later. Cloud saving must be on to use snapshots.

:::caution
Snapshots need cloud saving turned on. If a plan is local-only, taking a
snapshot won't be available switch cloud saving on in **Settings** first.
:::

## Import & export

Download a plan as a `.pp.json` file to back it up or share it; import one the
same way. Older files are upgraded automatically on load.

## Sharing

Make a plan **public** to share a view-only link. Anyone with the link can
look but not edit.

The active workspace view and sidebar panel are included in the URL. A copied
planner link can therefore open directly in the same Flow, Text, or Tree view
and panel.

## Community templates

The **Templates** page contains public plans that can be reused as starting
points. Search by plan, item, recipe, or building; filter by category; then
choose **Use template** to create a separate local plan and calculate it
immediately. The source template is not edited.

Signed-in users can publish a saved cloud plan with a category, copy its direct
template link, and unpublish it later. If using a template would replace an
unsaved local plan, the planner asks for confirmation first.

## Comparing plans

Put two plans side by side to compare power, buildings, inputs, and outputs.
This is handy for choosing between approaches. Either side can compare a
saved **snapshot** instead of the live plan, so you can see exactly what
changed since you took it.
