:::note
On macOS, use **Cmd** wherever these tables say **Ctrl**.
:::

## Elements

These apply to the selected element while the canvas has focus.

| Shortcut                       | Action                          |
| ------------------------------ | ------------------------------- |
| **Ctrl + C**                   | Copy the selected element       |
| **Ctrl + X**                   | Cut the selected element        |
| **Ctrl + V**                   | Paste                           |
| **Ctrl + D**                   | Duplicate the selected element  |
| **Delete** / **Backspace**     | Delete the selected element     |

Pasted and duplicated elements land slightly offset from the original, so they
are never hidden exactly behind it.

## Moving

| Shortcut               | Action                        |
| ---------------------- | ----------------------------- |
| **Arrow keys**         | Move by 1 px                  |
| **Ctrl + arrow keys**  | Move by 10 px                 |
| **Shift + drag**       | Lock the drag to one axis     |

## Canvas

| Shortcut                    | Action                          |
| --------------------------- | ------------------------------- |
| **Ctrl + scroll**           | Zoom in and out                 |
| **Drag empty space**        | Pan (when zoomed in)            |
| **Middle-mouse drag**       | Pan                             |
| **Click empty space**       | Clear the selection             |
| **Right-click**             | Context menu                    |

## Layer list

With a row in the **Layers** list focused:

| Shortcut                             | Action                     |
| ------------------------------------ | -------------------------- |
| **Arrow up** / **Arrow down**        | Move the selection         |
| **Ctrl + arrows** / **Alt + arrows** | Reorder the element        |
| **Delete**                           | Remove the element         |

## Elsewhere

| Shortcut       | Action                          |
| -------------- | ------------------------------- |
| **Ctrl + K**   | Search this documentation       |
| **Escape**     | Close a dialog or the tour      |
