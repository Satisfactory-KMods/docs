The canvas shows your sign at its real pixel size, scaled to fit the window.

## Moving elements

Drag an element to move it. While dragging:

- Hold **Shift** to lock movement to one axis.
- Elements **snap** to the sign's edges and to its centre lines when they come
  within a few pixels.

For precise work, select an element and use the arrow keys — **1 px** per press,
or **10 px** with **Ctrl** held.

## Overhang

Anything that reaches past the sign's edge is drawn **faded** rather than simply
disappearing, so you can see how far out it goes and pull it back. The mod crops
at the edge, so whatever is faded will not appear in game.

## Zoom and pan

| Action              | How                                                          |
| ------------------- | ------------------------------------------------------------ |
| **Zoom**            | **Ctrl + scroll**, or the `−` / `+` buttons below the canvas. |
| **Fit to window**   | The percentage button between them.                          |
| **Pan**             | Drag any empty space, or drag with the **middle mouse button**. |

Panning only does anything once you are zoomed in past the fit level — the grab
cursor appears when there is somewhere to pan to.

:::tip
A short click on empty canvas (without dragging) clears the selection, so
panning never costs you a deselect.
:::

## Right-click menu

Right-click an element for copy, cut, duplicate, delete and the layer-order
actions. Right-click empty canvas for paste, deselect, and quick "add text" /
"add effect" entries.

## Layers

The **Layers** list in the left panel holds every element on the sign.

- Click a row to select it.
- Drag the handle to reorder — the **bottom** of the list draws **on top**.
- The **×** removes it.
- With a row focused: arrow keys move the selection, **Ctrl/Alt + arrows**
  reorder, **Delete** removes.
