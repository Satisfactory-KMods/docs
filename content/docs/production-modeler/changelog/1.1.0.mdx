## NEW FEATURES

- Saved **Built** markers and node locks.
- Node footer: power + building/clock pills, clock input, click-to-cycle
  Somersloops.
- **Canvas controls:** zoom level, zoom buttons, fit-to-view (bottom-left).
- **Detailed minimap:** connections, selection, visible area; click to
  navigate.
- **Game data switcher:** swap installed packs in-model.
- **Reload selected data:** test edited packs without editor reload.
- **Refresh list:** pick up newly installed packs.
- **Pack editing:** rename imported packs; browser pack icons.
- **Selected-data fallback:** open models when their saved pack is missing.

## QUALITY OF LIFE

- **Settings** and **Leave with unsaved changes** dialogs redesigned.
- Wider node cards.
- **+ Add** removed from toolbar (double-click, right-click, keyboard remain).
- **Alpha** labels removed.
- Guides reworked; game-data instructions added.

## BUGFIXES

- Arrowheads aligned to receiving ports at every zoom.
- Unreachable fixed counts reported in buildings, not items/min.
- Graph edits, viewport, undo/redo kept when switching packs.
- Calculations/icons refresh when packs share a data version.
- Missing recipes/connections stay visible.
- Sidebar alignment with game-data notices.
- Compact Power Shard / Somersloop icons in inspector.
- Pending calculations/restores cannot overwrite a data switch.
- Unsaved-work warnings stay active if recovery fails.
- Catalog loading + calculation across model handoffs.
- Desktop port reorder by drag survives a mid-drag calculation.

## KNOWN ISSUES

- Switching ≠ importing: new `.kdata` still reloads the app. Save first. See
  [Game data](https://docs.k-mods.com/production-modeler/game-data/).
