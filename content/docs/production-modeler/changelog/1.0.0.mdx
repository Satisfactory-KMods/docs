## Baseline

- Factory canvas with recipe nodes, building controls, ports, and connections.
- Exact flow calculations, machine counts, clocks, Somersloops, and power totals.
- Shared calculation core for web and desktop.
- Offline desktop modeling with bundled game data and local recovery.
- Local models, opt-in cloud saving, snapshots, and sharing.
- Model import/export and reviewed starting points.
- Desktop sign-in through the system browser.
- Desktop update checks with release notes and user-controlled installation.
