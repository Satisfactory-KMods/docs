## NEW FEATURES

- **Auto Planner: several targets.** **Add another target** on the review step.
  - Shared intermediates and inputs produced once.
  - A target another chain also consumes gets its own producer.
- **Auto Planner: strategies.** Up to two on the review step, as in the Planner:
  Shortest Path (default), Shortest Chain, Fewest Resources, Low Power,
  Balanced, Byproduct Reuse (an add-on). The choice is remembered.
- **Add a node: categories.** Raw resources, liquids, gases, fuel, nuclear,
  organic, farming, packaging, Space Elevator parts, alternates, power, each
  machine. Mod packs included. Counts follow the search.
  - Category column on the right, each with an icon (machines: their building).
  - List grouped under category headings, each entry once; rest under **Other**.
  - **Settings**, **Appearance**: switch off for the old flat list.
- **Add a node: details.** Click grows the panel downward, no inner scrollbar.
  - I/O per minute and per cycle, liquids and gases in m³, recipe count per part.
  - Produced in with power drawn or made, cycle time, cycles per minute,
    energy per cycle.
  - Stack size, sink points, energy value, extraction per purity, fuels, build
    cost, unlock, wiki link.
  - Compact card: name, building icon and badges in one line, **Use recipe**,
    wiki link and **X** in its header, one line per part with the rate per
    minute (per cycle in the tooltip), the rest as labelled chip rows.
    Double click or Enter adds too.
- **Add a node: search and filters.** Search bar with a clear button; **/** or
  **Ctrl+F** jumps to it, **Escape** clears it before closing the panel.
  - Filter chips: type (recipes or buildings), alternates, favorites only, mod,
    tier, progression tier and which fields the search covers.
  - Every active filter shows as a chip that removes it; **Reset all** clears
    them and keeps the search.
- **Add a node: compact list and grid.** Tiles and list rows share one height
  and one order: icon, name, the building it runs in, then its parts on one
  line. The building icon names the building on hover.
- **Connection menu.** Right-click label or line, or Menu / Shift+F10 on a
  focused label.
  - Select source, target or chain; serve earlier/later; reset label; delete.
  - Read-only models: selection only.
- **Older desktop versions.** Download page lists earlier builds under
  **Older versions**. Oldest deleted automatically when storage is full.
- **Home page tabs.** Datapacks, Your Models, Public Models.
  - Own address each (`/production-modeler/datapacks`, `/models`, `/public`),
    last tab remembered. `/production-modeler/browse` opens Public Models.
  - Your Models and Public Models use the full page width.
- **Model library as file manager.**
  - Sidebar: library root and folders only.
  - List (default) or tiles, folders first. Root holds models without folder.
  - Double click / Enter opens, Backspace up, F2 renames folder, Delete deletes.
  - Drag models from the list, folders from list or sidebar, onto any folder.
    **Model library** or the first crumb moves to top level.
  - Folder menu: Open, New subfolder, Rename, Move to, Delete.
- **Model details pane.** Products, needs, interface rates, buildings, counts,
  folder, tags, revision, dates, game data status. Public models: Open, Copy
  to my models, Copy link.

## QUALITY OF LIFE

- **Power Shards and Somersloops needed.** Inspector sums them over the node's
  buildings, or over a multi-selection. Tooltip shows the sum per node.
  - One shard per started 50% above 100% clock; a partly used building runs
    at that part of the clock. Somersloops = slots × buildings.
- **Device settings on the home page.** Machine defaults, saves, numbers,
  appearance (desktop: updates, data) without a model.
- **Unsaved changes on leave.** **Settings**, **Saves**: ask (default), save,
  discard. Failed auto-save still asks.
- **Connection labels.** Click selects, drag moves.
- **Modular Miner in plans.** Both outputs on one belt.
- **Add a node favorites.** Starred entries in their own top row, per device.
- **Follow a part.** Click an input/output in the details to list its recipes.
  **Back** restores the search.
- **Search prefixes.** `in:` / `out:`, e.g. `in:coal out:steel ingot`.
- **Home page header.** Address bar, search, storage, sort, view, tags,
  **New model**, **Import file**, **New folder**. Patreon status on top.
  - Removed: Create/Planner links, stat tiles, public teaser. Counts in the
    status bar.
- **Header links.** **Datapacks** next to the other modeler links; only the
  open home tab is marked. Wiki header shows Models, Browse, Datapacks and Wiki
  as icons; in the desktop wiki window they open in the main window.
- **Window size remembered.** App and wiki window reopen with size, position
  and maximized state. Fullscreen and minimized not kept.

## BUGFIXES

- **Whole-machine rounding removed.** Broke calculations; counts stay exact.
  Old models and SFMD files ignore the option.
- **Even split behind exact values.** Exact rates first (also further down the
  chain), rest split evenly between Auto chains. No more chains at 0.
  Connection order still sets priority.
