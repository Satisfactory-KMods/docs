Hi Pioneers! Desktop wiki + map, inline port rates, model icons, snapping grid,
Refined Power big machines and burner manufacturers.

## NEW FEATURES

- Desktop wiki: records, images, translations from the active game-data pack.
- Desktop map: bundled tiles zoom 3–5, local savegame overlays. Higher zoom
  needs internet.
- Port rate on canvas: click → exact rate / upper limit / automatic. Decimals
  or fractions; fluids in m³/min.
- Getting-started guide (empty canvas, Help): add buildings, connect, set rate.
- One model library: device + cloud as one card. Folders via drag/drop or card
  menu (`/` = subfolder), filter by folder/tag/storage. Folders/tags on local
  models travel with first cloud save.
- Model icon + colour: Iconify or game image, colour preset or custom. Shown on
  cards and editor header.
- MDI icons browsable offline; tags/folders reusable from model details.
- Canvas grid: toggle next to Fit, scales with zoom, snap grid, default cell 50.
- Connection labels snap to grid by centre; on 2D routes level with nearby port.
- Ctrl while dragging building/label/waypoint: invert snapping for that drag.
- Storage output without part/rate/connection shows input part at input rate;
  wiring it hands that part on.
- Savegame buildings on map: per-type toggles, search, real pickup icons;
  footprints and splines as geometry.
- Underground caves/entrances toggle; world-object category grids with select/
  clear; slug item icons.
- Deposits keep bound resource, remaining amount, hand-mining yield.
- Home hero: wrapping version, update controls, build info restored; slim
  update/version bar in editor.
- BurnerManufacturer recipes: separate selectable fuel input; clock +
  Somersloop power scaling, no grid demand.
- Refined Power Solar Tower: fluid recipe, linked/visible mirrors, daylight
  snapshot; installed mirrors in building/construction/power totals.
- Icarus receiver (single): daytime, cooldown, orbital stock. Orbital upkeep
  independent of duty; Railgun power separate. Launch batches / tick charging
  not simulated.
- Refined Power Modular Reactor: 10 chambers, I/O ring, cooling addon,
  shielding, fuel, coolant, heat, clock, tick rate, steam, power.

## QUALITY OF LIFE

- Model cards: storage location, folder, tags, in-place editor with tag
  suggestions, right-click menu (move to folder, remove local copy, delete
  cloud copy).
- `.kdata` v2 with optional wiki data; v1 still readable; wiki section kept on
  export.
- SatisfactoryPlus bundled as `.kdata` alongside Vanilla.
- Browser `.kdata` upload 128 → 512 MiB, up to 10,000 files.
- Fewer redraws/summary recalcs on select/move; summary settings no longer
  restart the solve.
- Building count pinned in footer chip (solved = placeholder, typed = fixed,
  cleared = automatic). Header field removed.
- Card names one line + ellipsis, full name in tooltip. Cards +50 px, footer
  chips same height.
- One dialog anatomy site-wide: eyebrow, title, description, content, footer;
  Escape/backdrop.
- Outpost/Blueprint as sub-factory: same ports both sides. Overview input →
  "From outside" inside; "To outside" inside → container output. Old wiring
  still works.
- Model details via icon/colour/name in editor header; edit/details buttons
  removed.
- Tooltip amounts: 4-decimal numbers, not fractions ("9549/80/min"). Custom
  formats kept.

## BUGFIXES

- Saved canvas position/zoom kept when opening an imported model.
- Model settings saved after changing recipe input / power / Space Elevator
  multipliers.
- Wiki language switch applies immediately.
- Outpost without connected supply = external production sized to demand;
  explicit limits kept; balanced once supply is connected.
- Imported `.kdata` packs load again (schema-filled part fields failed the
  integrity check: "Required game data is missing").
- "Recover local draft" no longer returns every visit; restored draft
  continues the cloud copy, next save accepted.
- Draft creation date + backup marker kept across saves; "Saved" toast once.
- Desktop logo click → app home, not k-mods.com.
- Icarus stocks + port identities kept when mapping renamed orbital items in a
  game-data migration.
- Game image as model icon saves to cloud without 422; same formats
  everywhere.
- Draft recovery actions disabled while loading / another operation runs.

## GAME DATA

- Bundled Vanilla + SatisfactoryPlus: catalog only. Desktop wiki needs a
  `.kdata` with wiki data. v1 packs still model. Modeler ≤ 1.2.1 cannot import
  v2.
- BurnerManufacturer, Solar Tower, Icarus, Modular Reactor need a fresh
  KModelerExporter export; missing metadata → diagnostics, no calculation.
