Hi Pioneers! Vanilla game data ships with the desktop app, the app tells you
which build you are running, and updates come with proper notes and a snooze
button.

## NEW FEATURES

- Include Vanilla game data in the desktop app as a separate ready-to-use
  profile. Vanilla shows in the web collection with an explicit desktop-only
  availability notice. Existing profiles and the active selection stay.
- The installed desktop version, commit and build date show on the home page.
- Read the installed and earlier patch notes inside the desktop app, also
  offline. Open the version history from the home page, Help or the update
  dialog.
- A dedicated update dialog opens when a new version is available, with a link
  to the patch notes and a visible update reminder on the home page.
- Close an update reminder until the next app start, skip that specific
  version, or install it. A skipped update stays available from the home page.

## QUALITY OF LIFE

- The update dialog shows download and installation progress. Unsaved model
  changes are settled before an installation starts from the workspace.

## BUGFIXES

- Save and sync valid models even when their older or local game-data version
  is unavailable in the cloud. The original game-data binding is preserved and
  the previous cloud revision is snapshotted before it is replaced.
