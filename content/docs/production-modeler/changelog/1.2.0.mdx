## NEW FEATURES

- Include Vanilla game data on desktop as a ready profile; web collection
  shows it desktop-only. Existing profiles/selection kept.
- Home page: installed version, commit, build date.
- Patch notes in-app, offline; version history from home, Help, update dialog.
- Update dialog on new version: notes link + home-page reminder.
- Update reminder: close until next start, skip version, or install. Skipped
  update stays on home page.

## QUALITY OF LIFE

- Update dialog shows download/install progress; unsaved changes settled
  before install from workspace.

## BUGFIXES

- Save/sync models whose older or local game-data version is missing in the
  cloud; binding kept, previous cloud revision snapshotted.
