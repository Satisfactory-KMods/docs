Hi Pioneers! Sub-models, one Existing Factory node, a full planet survey on
the map, water dam nodes, and a solver that no longer leaves buildings idle.

## NEW FEATURES

- **Sub-model node.** Place another model as one node.
  - Interface: **Model Input** / **Model Output** nodes in the placed model, one
    part each, pooled by part.
  - Ports carry one copy's I/O; count solved like recipe buildings, whole
    copies by default, copy limit as ceiling or exact.
  - Per-copy power consumed/produced added to totals.
  - No overclock, no Somersloops. Lockable, markable as built.
  - Sources: own cloud models, local drafts, public models. Self-reference
    and cycles refused.
  - **Sub-models** tab: this model's interface + placed models with copies and
    MW. Open model (browser: new tab; desktop: same window with back link).
    Refresh on open when the source revision changed, and on request.
- **Blueprints.** Save a selection under a name, icon and colour (suggested
  from the end product and its solved rate); place it from its catalog as a
  production line (the nodes as copied plus Model Input/Output for open
  parts, factory ports inside a factory) or as one Existing Factory whose
  ports are the selection's open ports, one per part, wired. One undo step,
  built and locked marks dropped. Always kept on the device without a limit
  and, while signed in, mirrored to the account (50, Patreon 2,000; a full
  account leaves new ones on the device until there is room). Newer side wins,
  a deletion elsewhere is followed. Switch under **Settings**, **Saves and
  recovery**.
- **Grid or list in the catalogs.** The blueprint catalog and the sub-model
  picker take the palette's view toggle: tiles with part icons or rows naming
  them, one remembered choice for both. Palette port icons read stronger.
- **Factory ports as nodes.** Inside an Existing Factory its ports stand as
  nodes: drag them, wire them, add **Factory input** / **Factory output** from
  the palette. Model unchanged; only the port position is stored.
- **Catalogs for models and nodes.** **Switch model** (**Ctrl + O**) and
  **Find a node** (**Ctrl + F**) are card catalogs with search, filters and
  long hover cards.
- **Existing Factory counts itself.** Empty factory + rate on each port = I/O
  per factory. Drawn count is the start; solver grows it on demand; limit caps
  it. Machines inside: port rates are boundary limits, count is manual.
- **Special node tooltips.** Palette hover: what it is, how to use it, why it
  exists. All 12 special nodes.
- **Existing Factory node.** Outpost + Blueprint merged. Boundary ports,
  count, title, item/building icon, stated MW consumed/generated (counted in
  summary). Inputs ordered before outputs. Old models, SFMD imports and share
  links load unchanged.
- **Map: planet survey.** Crash sites (unlock cost: item + count or MW; save
  marks collected drives), roads, spawn points, world border, gas pillars,
  spore flowers, large/small rocks (save marks cleared). Offline.
- **Map: vehicles and trains.** Trucks, tractors, explorers, factory carts,
  drones, locomotives, freight wagons from a save as one world-object group.
- **Map: water dam nodes.** Refined Power dam nodes with dam line, section
  count, MW at spot; save marks built dams/turbines. Needs fresh export.

## QUALITY OF LIFE

- **Map panel.** Wider, pushes map aside, compact rows. Saved buildings grouped
  by build-menu category/sub-category. Caves, crash sites, world layers in one
  Map layers section.
- **Map lines to scale.** Belt 1.35 m, rail 6 m, road 25 m; scale with zoom.
  Power lines drawn pole-to-pole/machine. Hover = length.
- **Map deposits.** Own Deposits section, hexagon markers, per-resource toggle,
  on by default.
- **Map caves.** Underground caves/entrances on by default; Underground section
  toggles.

## BUGFIXES

- Leave button while a container is open; deleted container auto-leaves.
- Wiki window on Windows: white/unclosable. Window built in sync command →
  event-loop deadlock. Now async. Wiki window no longer requests update checks.
- Container boundary: child output to a boundary port with nothing wired
  outside was forced to 0 ("can only reach 0"). Now leaves the model. Pinned
  boundary rate counted once, not half in/half out.
- Saved buildings with a mod/folder class (Pipeline Mk.2, Seed Extractor) or
  build-menu-only entry show real name/icon/category. Unknown classes: readable
  name + "?" instead of vanishing.
- Power slug icons back on the desktop map (markers + legend).
- Dead-end auto building takes full upstream supply (auto-count miner, storage
  fed by several producers) instead of stopping at 1 with a surplus warning.
- Exact rate / upper limit on a merged Modular Miner output keeps the port
  rate, count follows; automatic restores.
- Burn-recipe generators (Coal, Fuel, Nuclear): power linear with clock. Was
  using the consumption curve (22 × 250% > 55 × 100%).
- Dev site / dev desktop share links → dev.k-mods.com.
- Two auto-count miners on one chain: larger drawn supply used whole, other
  miner grows to match. 240 crushed ore no longer idle behind one SAM node.
- All amounts decimal (217.5, not 435/2): warnings, tooltips, edit fields,
  arrow-key steps. Fraction number style removed.
