- **Double-click empty space:** open the node palette at that position.
- **Right-click empty space:** open the same palette.
- **Left-drag empty space:** pan. **Mouse wheel:** zoom around the cursor.
- **Right-drag:** draw a selection box. **Shift** or **Control:** extend selection.
- **Middle-click:** paste the copied selection.

You can also hold **Shift** and left-drag empty space to draw a selection box.
Both selection boxes include every card they overlap, even if part of the card
extends outside the box. You do not need to enclose the whole card.

The toolbar no longer has a **+ Add** button. Palette keyboard access remains
available; see [Keyboard shortcuts](/production-modeler/shortcuts/).

Select a node to highlight its connected wires. Right-click it for editing,
copying, selecting its chain, disconnecting, or deleting. Double-click a node
to edit it in the Inspector. On narrow screens, select it and choose **Edit**
to open the panel. Double-click a container to enter it.

The bottom-left controls show the live zoom percentage. Use **Zoom out** and
**Zoom in** to change it, or **Fit canvas to view** to frame your selection.
With nothing selected, it fits the current container. These controls also work
in read-only models.

The bottom-right **Minimap** shows nodes, connections, selected nodes, and the
visible area. Click it to move the view without changing zoom. Focus it and use
arrow keys to pan, or **Enter** / **Space** to fit the current container.
Collapse it with the header button. It starts collapsed when the canvas is narrow
or short, and shrinks to stay within the available space when opened.

Use **Arrange** or **L** to lay out the selected nodes along their connections.
Arrow keys nudge the selection; hold **Shift** for larger steps.

## The panel beside the canvas

The side panel has three tabs:

- **Summary:** totals for the model, container, or selection.
- **Inspector:** settings for the selected node or connection.
- **Messages:** calculation errors, warnings, and other diagnostics.

Selecting a node opens the Inspector on desktop. On narrow screens, use **Edit**
to open it. Selecting a diagnostic reveals its node, including nodes inside
another container. Repeated diagnostics are grouped;
copy the list when reporting a problem.

The panel can be resized or hidden. On narrow screens, open it with the summary
button and close it to return to the full canvas. The button shows when errors
or warnings are waiting.

Game-data and model-status notices sit above the canvas, not above the side
panel. A long-running solve also offers a stop action there. See
[Panels](/production-modeler/panels/) for each tab's controls.

## Connections

1. Drag from an output port to a compatible input port.
2. Drop on empty space instead to open a filtered palette.
3. Pick a compatible node to place it already connected.

Arrowheads point into the receiving port. Select a node or connection to see
its highlighted wires flow from source to target. If your system requests
reduced motion, flow and loading spinners run more slowly. Decorative node
effects stay disabled.

Ports can carry several connections. In Full mode, their order controls
priority where allocation is required. Reorder connections in the Inspector.

A port limit can be an **exact rate** or an **upper bound**. A ceiling does not
force production to reach it. Limits also work on supported non-recipe buildings,
not just ordinary recipe nodes.

A solved connection shows an automatic estimate of the belt or pipe needed for
its rate. The badge shows when more than one line is needed. It is not a picker
for assigning a particular transport to the connection.

Copied selections use the system clipboard, so they can move between models,
tabs, or windows. Browser clipboard permissions may be required.

## Waypoints

- Double-click a connection to add a waypoint.
- Double-right-click a waypoint to remove it.
- Double-right-click a connection to delete it.
- Move both endpoints together to move their waypoints with them.

Drag a connection's rate label to adjust its routing. Double-click the label
to reset its manual placement. Label changes can be undone and saved with the
model.

Choose curves, direct lines, or orthogonal routing in
[Settings](/production-modeler/settings/#connections-and-grids).

## Grids

The decorative background grid is not a snap target. Two working grids control
placement:

- **Building grid:** snaps nodes.
- **Connection grid:** snaps waypoints.

Each has independent X and Y spacing. Apply a grid to the whole model, current
outpost, or selection. Nudging follows the building grid when it is enabled.
Review the scope before applying a grid to existing work.

## Node status and quick controls

The **Fixed building count** field in a node header sets exactly that many
buildings running at the configured clock. It is not an item rate or a count of
installed buildings allowed to idle. Clear it to return to **Auto**. Recipe
nodes take it, and so do extractors and Modular Miners, where it says how many
of them stand on the node.

A fixed count is a plan, so what it produces is meant to be used: the chain
behind it grows to consume it, including source counts drawn as a single
building, rather than leaving that production unused. Connected
upstream limits still apply. If a fixed count needs more than its supply can
provide, the whole connected group shows **N/A** until the conflict is resolved.
The error reports the requested buildings and the reachable building-equivalents,
not items per minute. Increase the upstream supply, allow an extractor's count
to grow, or lower the fixed count or clock. Changing the downstream node to
**Auto** does not override a fixed upstream ceiling.

Use the checkmark at the bottom of a node to mark it **Built**. This tracks what
you have built in the game and is kept with the saved model. Built cards have a
uniform green outline and glow, with no extra stripe along the top. When both
ends of a connection are built, the line turns green and its rate label gains a
matching highlight. Clearing **Built** on either end restores the normal connection
styling. Diagnostic icons remain visible on built connections.

The lock beside it protects a node from moving, editing, connecting,
disconnecting, or deleting. You can still select a locked node and inspect its
details. Unlock it before making changes; its lock state is also saved.

Machine nodes keep their quick controls in a compact bottom section, visible
even when recipe details are collapsed:

- **Power:** a pill showing the calculated power use or production.
- **Buildings and clock:** a pill showing the calculated machine count and
  per-building clock percentage, such as **1 × 20%**. Use its copy button to copy
  just the percentage number for the game's clock input. The copied value has
  up to six decimal places, without a `%` sign, even if the card displays a
  rounded value or fraction. Copying also works on locked nodes and read-only
  models.
- **Clock setting:** edit the percentage beside the Power Shard icon to change
  the configured clock. This can differ from the calculated per-building clock.
- **Somersloops:** click the pill to add one, up to the machine's slot limit.
  Clicking again at the limit resets it to zero.

Available controls depend on the building. The
[Inspector](/production-modeler/panels/#inspector) keeps the detailed settings.

## Outposts and blueprints

**Outposts** group part of a factory. Double-click to enter; press **Escape** to
leave. Each container keeps its own pan and zoom. **Select All** affects the
container you are currently viewing.

**Blueprints** scale a repeated section by a count. Use one instead of drawing
the same sub-factory repeatedly. Boundary ports carry connections between a
container and the surrounding graph.

The header trail shows where you are. Use it to return to a parent container.
A closed container shows a summary without requiring you to enter it.

## Aligning a port

Choose **Align to connection** in the Inspector to move the node vertically
until its port lines up with the connected port. Horizontal placement stays
unchanged. If the port has several connections, the first one is used.
