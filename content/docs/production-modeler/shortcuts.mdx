The same list is in the modeler itself. Press the question mark key or F1 to
open it. The dialog groups shortcuts by editing, canvas navigation, and model
actions, with mouse and touch gestures shown separately. Keys joined by a plus
sign are pressed together; "or" separates alternative combinations. It shows
Ctrl on Windows and Linux, Cmd on macOS, and translated key names in German.

:::note
On macOS use **Cmd** wherever this page says **Ctrl**.
:::

## Keys

| Shortcut | Action |
| --- | --- |
| **Ctrl + Z** | Undo the last model transaction |
| **Ctrl + Y** / **Ctrl + Shift + Z** | Redo the last undone transaction |
| **Ctrl + A** | Select every node in the current container |
| **Ctrl + C** or **Ctrl + Insert** | Copy the selection |
| **Ctrl + X** or **Shift + Delete** | Cut the selection |
| **Ctrl + V** or **Shift + Insert** | Paste copied nodes |
| **Delete** / **Backspace** | Delete the selection |
| **Ctrl + S** | Save the local or cloud revision |
| **A** / **Insert** | Add a node at the centre of the canvas |
| **Enter** | Focus the selected node in the inspector |
| **Escape** | Close a popup, or leave the current container |
| **?** / **F1** | Open the shortcut list |

A shortcut is ignored while you are typing in a field or while a dialog is open,
so **A** in a search box adds a letter and not a node.

Ctrl + L cannot be taken from the browser reliably, so there is no language
shortcut. Change the language in the settings dialog.

## Mouse

Pan with the left button and zoom with the wheel around the cursor. Drag with
the right button to pull a selection box, and hold Shift or Ctrl while you do to
add to the selection instead of replacing it.

Double click empty canvas to open the palette, or right click for the same menu.
Right click a node instead and you get that node's own menu. The middle button
pastes what you copied.

Double click a container to enter it. Double click a connection to add a
waypoint. Double right click a waypoint to remove it, and double right click a
connection to delete the connection.

## Touch

Drag with one finger and pinch to zoom. Tap ports to connect them, and use the
toolbar for the selection actions the keyboard would otherwise cover.
