Each page here starts from a **goal** and walks through however many files and document types it
takes to get there. Every page includes complete, working YAML that you can copy directly.
[Features](/kdataforge/features) explains individual capabilities, while
[Reference](/kdataforge/reference) provides normative fields and APIs.

If this is your first pack, start with [Getting Started](/kdataforge/getting-started)
before the guides below. It builds the smallest possible pack and confirms it loads, then covers
`/kdf` commands, debug logging, the load report, session restarts, and current multiplayer limits.
That is the groundwork these guides assume.

If you're not sure whether you want a tutorial or a reference page, here is the difference.
Task Guides assume you know the basics from [Getting Started](/kdataforge/getting-started)
and are trying to get one specific thing working. Use [Features](/kdataforge/features)
for conceptual and per-capability explanations. Use [Examples](/kdataforge/examples)
when you want complete, copy-pasteable packs that wire several capabilities together.
