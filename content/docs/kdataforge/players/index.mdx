KDataForge loads content packs for Satisfactory. A pack can change recipes and progression, add
items or buildings, configure sounds, or alter parts of the world. Pack authors describe those
changes in YAML files. You do not need to edit those files to use a finished pack.

Use the pack author's installation and compatibility instructions first. KDataForge can load packs
distributed as mods and packs copied into the game directory, so two packs may use different
installation methods.

## Choose a task

- [Install, update, or remove a pack](/kdataforge/players/install-and-update-packs) covers managed
  and manual installs, verification, save backups, and removal risks.
- [Pack settings and multiplayer](/kdataforge/players/settings-and-multiplayer) explains who can
  change gameplay settings, which audio settings stay local, and why every game process needs the
  same pack files.
- [Troubleshoot a pack](/kdataforge/players/troubleshooting) starts from visible symptoms and uses
  `/kdf report` plus the game log to narrow down the cause.

If you want to create or modify a pack, start with
[Create your first pack](/kdataforge/getting-started). The pages in this section assume you only
want to play with an existing pack.
