KDataForge Editor is a standalone Windows editor for local KDataForge projects. It combines a pack
manager, code and visual YAML editors, reflection browser, validation, project tools, Git, and game
logs. A KDataForge pack still runs in the game; the editor prepares and checks its files.

## Start

1. Choose **Projects → Create**, **Open**, or **Clone**. Open a project containing `DataForge/` or a
   pack directory with `pack.yml`.
2. Import a `.kdfdata` reflection archive in **Datapacks**, then preview and bind it to the project
   for class and property metadata. Schema-only editing also works.
3. Open a pack in **Pack manager**. Edit YAML in **Code editor** or **Visual editor**.
4. Review **Problems**, run a full lint, and test the enabled pack in game.
5. Export a checked pack or prepare release metadata when ready.

Built-in providers have local on/off switches in **Built-in Modules** or **Settings → Built-in Modules**. Validated
`.kdfdata` archives also appear there as game-data resources. [ContentLib Import](/kdataforge/desktop-editor/contentlib-import)
converts a different source format into a new pack.

Reflection archives and ContentLib source folders serve different purposes. **Datapacks** accepts
`.kdfdata` only. **ContentLib Import** reads a `ContentLib/` folder, previews generated YAML and
warnings, then creates a new pack.
