KDF Assist has two entry points: the desktop **KDF Assist** page and a local stdio MCP server.
Both use bounded project YAML and reflection data. A model can suggest files; it does not write
project files through a model tool.

## In the desktop app

1. Open a project. Bind a `.kdfdata` archive if class defaults or property lookup matter.
2. Enable **KDF Assist** in **Plugins**, then open **KDF Assist** from navigation.
3. Set an OpenAI-compatible Chat Completions endpoint and model ID. HTTPS is required except for
   localhost HTTP. The API key remains in memory for the current page session; endpoint and model
   ID are stored locally.
4. Choose **Ask project**, **Balance recipe**, **Production chain**, or **Diagnose pack** and send
   a prompt. The configured endpoint receives selected project context and requested read-only
   lookup results.
5. Inspect suggested YAML and paths. **Preview and validate** checks current files and lint
   diagnostics. **Apply reviewed files** requires a fresh preview with no lint errors. A file
   changed since preview fails the expected-hash check instead of being overwritten.

Reflection can be ready, limited, or missing. Missing data cannot prove that a class is absent.
Review any suggested class path against the game/mod set used for the export.

## External MCP client

The bundled `kdf-mcp-server` runs over stdio with an explicit project root. `--datapack` is
optional; without it, class lookup has no reflection index.

```json
{
  "mcpServers": {
    "kdf": {
      "command": "C:/path/to/kdf-mcp-server.exe",
      "args": ["--project", "C:/path/to/project", "--datapack", "C:/path/to/reflection.kdfdata"]
    }
  }
}
```

Available tools are `project_overview`, `search_classes`, `get_class`, `search_documents`,
`read_document`, and `validate_draft`. The server also exposes an overview resource and the
`balance-recipe`, `design-production-chain`, and `diagnose-pack` prompts and skill resources.
It has no network listener or project-write tool. Your MCP client decides what it sends to its
model.
