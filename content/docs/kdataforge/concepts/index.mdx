Use these pages when you need a mental model before choosing fields from the reference.

- [Core concepts](/kdataforge/concepts/core-concepts) explains packs, documents, targets,
  operations, generated identities, load order, reload behavior, and multiplayer.
- [Choose an authoring tool](/kdataforge/concepts/choose-an-authoring-tool) compares handwritten
  YAML, the in-game editor, the desktop editor, the linter, and the Unreal Editor integration.
- [Architecture](/kdataforge/background/architecture) follows the runtime pipeline in detail for
  contributors and native mod developers.
- [Module structure](/kdataforge/background/module-structure) documents the C++ module boundaries.

For a guided first pack, use [Create your first pack](/kdataforge/getting-started). For exact
fields and accepted values, use the [reference](/kdataforge/reference).
