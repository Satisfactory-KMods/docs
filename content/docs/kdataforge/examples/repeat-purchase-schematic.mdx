---
title: Removed repeat-purchase unlocks
description: Migrate an old KLib repeat-purchase reward pack to Delivery tasks.
sidebar:
  hidden: true
---

The custom `KLUnlockMaxRepeatPurchases` unlock, its challenge Blueprint, and its purchase-count
and level-dependent reward system have been removed. Existing YAML that references that class
must be updated; enabling KLib no longer provides it.

Use [Delivery Task Trees](/kdataforge/examples/delivery-task) to define repeatable tasks,
completion-specific rewards, and cost growth. Remove the obsolete schematic unlock from your
pack. Unused cost/reward curves can be removed once no other content references them.
