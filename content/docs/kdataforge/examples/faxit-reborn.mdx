# Faxit Reborn Reference Pack

Faxit Reborn is an installable reference pack built entirely from KDataForge YAML. It requires
KDataForge, KAPI, KPrivateCodeLib, and KLib, but no SatisfactoryPlus content. Copy its complete
[`FaxitReborn` directory](https://github.com/Satisfactory-KMods/modding/tree/fresh-dev/Mods/GameFeatures/KDataForge/Docs/13.reference-packs/FaxitReborn)
into `<GameFolder>/FactoryGame/`, preserving `FaxitReborn/DataForge/`. Restart session, then run
`/kdf report`. Current pack version: `2.0.0`.

Faxit Reborn is an alternative to SatisfactoryPlus. Pack condition intentionally skips all
documents while SatisfactoryPlus is installed.

Pack creates 254 delivery tasks: twenty Nexus nodes, feature branches, calibration gates, transfer
rate upgrades, ten repeatable Somersloop/Mercer Sphere endpoints, 100 post-endpoint upgrades,
Delivery Queue I-X, Depot Upload Speed I-X, eighteen Project-Part recycling nodes, and six
Hazardous Logistics nodes.

Nexus XI-XX adds ten `Network +1` unlocks, ending at twenty networks. Delivery Queue I-X adds ten
queue slots; existing progression reaches four slots first, producing final limit fourteen. Depot
Upload Speed I-X applies ten five-percent upload-time decreases, 50 percentage points total.

Project-Part Recycling is separate tree. License appears after Phase 1 and costs exactly ten
Resource Sink Coupons. Five phase gates use `EGP_MidGame`, `EGP_LateGame`, `EGP_EndGame`,
`EGP_FoodCourt`, and `EGP_Victory`. Twelve repeatable contracts cover all Project Parts. Their base
lots are 20-100 parts; constant `50×` curve produces effective costs of 1,000-5,000 parts.
Hazardous Logistics is another separate tree with phase-gated contracts for Uranium Fuel Rods,
Uranium Waste, Plutonium Fuel Rods, Plutonium Waste, and Ficsonium Fuel Rods. Its same curve produces
effective costs of 50-5,000 radioactive items.

Every recycling or hazardous contract grants exactly one Somersloop and two Mercer Spheres, up to
50 completions. No delivery node rewards Resource Sink Coupons or other Resource Sink items;
coupons are costs only.

Each repeatable endpoint opens two five-node chains after ten completions:

- one chain grants five player inventory slots;
- one chain grants five Dimensional Depot item-stack-limit increases.

Every upgrade node costs one matching alien artifact plus Resource Sink Coupons scaled by local
branch step: `1`, `2`, `3`, `4`, then `5`. Each node grants exactly `+1`. Both branches behind one
endpoint therefore cost 10 artifacts and 30 coupons. Across all ten endpoints, pack adds 50 player
inventory slots and 50 Depot stack upgrades for 300 coupons total.

See [Delivery Task Trees](/kdataforge/examples/delivery-task) for node-link semantics and
[Data Assets](/kdataforge/features/data-assets) for generated `UKAPIDeliveryTask` instances.
