Reference pages describe exact syntax and contracts. For a guided task, use the
[How-to guides](/kdataforge/tutorials). Use [Authoring concepts](/kdataforge/concepts) for the
underlying model and [Document types and features](/kdataforge/features) for behavior specific to
a document type.

## Pack-author reference

- [Commands and console variables](/kdataforge/reference/commands) lists chat, runtime console,
  reflection, and Unreal Editor commands with permissions and process boundaries.
- [YAML schema](/kdataforge/reference/yaml-schema) defines pack manifests, document types,
  property paths, all 25 operations, conditions, and includes.
- [Configuration expressions](/kdataforge/reference/config-expressions) defines `config:`
  operands, operators, evaluation, and diagnostics. Use it with
  [Pack configuration](/kdataforge/features/pack-configuration) and
  [Templates and typed references](/kdataforge/features/templates).
- [Base-game unlock classes](/kdataforge/reference/base-game-unlock-classes) catalogs each
  base-game `FGUnlock` subclass, its path, properties, examples, and instantiation constraints.
- [Mod unlock classes](/kdataforge/reference/mod-unlock-classes) catalogs unlock classes supplied
  by installed mods, including their Blueprint paths.
- [Availability dependency classes](/kdataforge/reference/availability-dependency-classes)
  catalogs `FGAvailabilityDependency` classes, their abstract state, paths, and fields.

## Authoring tools

- [Desktop editor and LSP](/kdataforge/reference/desktop-editor-lsp) covers `.kdfdata` import,
  project binding, reflection requirements, schema-only editing, and diagnostic status.
- [Reflection export](/kdataforge/reference/reflection-export) defines export commands, options,
  archive contents, function and setting indexes, texture previews, validation, publication
  recovery, and reload classification.

## Native developer reference

- [API design](/kdataforge/reference/api-design) documents the public C++ contract in
  `KDataForgeApi` for third-party mods.
- [Template provider API](/kdataforge/reference/template-provider-api) documents native custom
  `{prefix:body}` values, phases, result states, registration, and diagnostics.
- [Blueprint configuration API](/kdataforge/reference/blueprint-config-api) documents pack and
  field queries, typed values, pending changes, apply/reset flows, events, and multiplayer writes.
- [Handler template](/kdataforge/reference/handler-template) provides a C++ implementation pattern
  for adding a YAML root type to KDataForge.
- [UE editor integration](/kdataforge/reference/editor-integration) documents
  `KDF.ApplyToAssets`, which applies supported `cdo` patches to assets in Unreal Editor and marks
  their packages dirty. It does not run in the packaged game.
