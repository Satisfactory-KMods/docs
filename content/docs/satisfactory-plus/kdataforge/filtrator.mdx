Define a Filtrator recipe as a `KAPICleanerItemDescription` instance in a
`type: dataasset` document. This replaces creating the asset in Unreal Editor.
See the
[full property reference](/satisfactory-plus/kapi/filtrator/) for every field, including
`FKAPICleanerInfo`.

This example reproduces Satisfactory Plus's shipped "Filtrator filter
Wastewater" recipe: 6000 wastewater in, 4000 clean water out over 6 seconds,
plus two bypass products, crushed zinc and crushed caterium, produced
independently of the main fluid conversion. The optional `mCleanerItemInfo` is
omitted because this recipe requires no extra cleaner item
(`mCleanerItemInfo.mProduceItem` is `None` in the shipped asset):

```yaml
# file: filtrator-wastewater.dataasset.yml
type: dataasset
conditions: { hasMod: KAPI }
assets:
  - id: CleanerItem_WasteWater
    class: /Script/KAPI.KAPICleanerItemDescription
    properties:
      - path: bSkipUnlockCheck
        value: false
      - path: mProductionTime
        value: 6
      - path: mInFluid
        value:
          {
            ItemClass: /KLib/Assets/Ressources/Raw/Fluids/Desc_Wastewater.Desc_Wastewater_C,
            Amount: 6000,
          }
      - path: mOutFluid
        value:
          {
            ItemClass: /Game/FactoryGame/Resource/RawResources/Water/Desc_Water.Desc_Water_C,
            Amount: 4000,
          }
      - path: mBypassProducts
        value:
          - {
              mProduceItem: /KLib/Assets/Parts/Production/Crushed/Desc_CrushedZinc.Desc_CrushedZinc_C,
              mProductionTime: 12,
              mProduceAmount: 6,
            }
          - {
              mProduceItem: /KLib/Assets/Parts/Production/Crushed/Desc_CrushedCaterium.Desc_CrushedCaterium_C,
              mProductionTime: 12,
              mProduceAmount: 6,
            }
```

See [Adding KAPI Data Assets](/kdataforge/examples/kapi-data-assets/) for a
`type: dataasset` example of every KAPI type.
