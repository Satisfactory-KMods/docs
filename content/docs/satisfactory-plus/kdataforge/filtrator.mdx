---
title: 'Adding new Recipes to Filtrator'
description: How to add new Recipe DataAssets to the Filtrator in Satisfactory Plus through KAPI. To allow them in SF+ gameplay.
sidebar:
  order: 3
---

Add a Filtrator recipe as a `KAPICleanerItemDescription` instance with a `type: dataasset`
document instead of creating it in the Unreal Editor. See the
[full property reference](/satisfactory-plus/kapi/filtrator/) for every field, including
`FKAPICleanerInfo`.

The example below reproduces Satisfactory Plus's own "Filtrator filter Wastewater" recipe: 6000
wastewater in, 4000 clean water out over 6 seconds, plus two bypass products (crushed zinc and
crushed caterium) produced independent of the main fluid conversion. `mCleanerItemInfo` is left out
entirely it's optional, and this real recipe ships with no extra cleaner item required
(`mCleanerItemInfo.mProduceItem` is `None` in the shipped asset):

```yaml
# file: filtrator-wastewater.dataasset.yml
type: dataasset
conditions: { hasMod: KAPI }
assets:
  - id: CleanerItem_WasteWater
    class: /Script/KAPI.KAPICleanerItemDescription
    properties:
      - path: bSkipUnlockCheck
        value: false
      - path: mProductionTime
        value: 6
      - path: mInFluid
        value:
          {
            ItemClass: /KLib/Assets/Ressources/Raw/Fluids/Desc_Wastewater.Desc_Wastewater_C,
            Amount: 6000,
          }
      - path: mOutFluid
        value:
          {
            ItemClass: /Game/FactoryGame/Resource/RawResources/Water/Desc_Water.Desc_Water_C,
            Amount: 4000,
          }
      - path: mBypassProducts
        value:
          - {
              mProduceItem: /KLib/Assets/Parts/Production/Crushed/Desc_CrushedZinc.Desc_CrushedZinc_C,
              mProductionTime: 12,
              mProduceAmount: 6,
            }
          - {
              mProduceItem: /KLib/Assets/Parts/Production/Crushed/Desc_CrushedCaterium.Desc_CrushedCaterium_C,
              mProductionTime: 12,
              mProduceAmount: 6,
            }
```

See [Adding KAPI Data Assets](/kdataforge/examples/kapi-data-assets/) for every KAPI type's
`type: dataasset` example in one place.
