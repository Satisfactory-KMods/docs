Register a Modular Miner raw-resource entry as a
`KAPIModularMinerDescription` instance in a `type: dataasset` document. This
replaces creating the asset in Unreal Editor. See the
[full property reference](/satisfactory-plus/kapi/modular-miner/) for every
field.

This example mirrors a shipped Cryolite raw-ore entry:

```yaml
# file: modular-miner-cryolite.dataasset.yml
type: dataasset
conditions: { hasMod: KAPI }
assets:
  - id: MM_Cryolite
    class: /Script/KAPI.KAPIModularMinerDescription
    properties:
      - path: mIsFallbackDescriptor
        value: false
      - path: mNeededModules
        value:
          - /KAPI/Attachments/ModularMiner/Attachment_MM_MiningHead.Attachment_MM_MiningHead_C
      - path: mPreventModules
        value:
          - /KLib/Assets/Buildings/ModularExtractor/Modules/Smelter/Build_SmelterModule.Build_SmelterModule_C
      - path: mResourceClass
        value: /Game/FactoryGame/Resource/RawResources/RawQuartz/Desc_RawQuartz.Desc_RawQuartz_C
      - path: mDrillTier
        value: 1
```

`mFluidInfo` and `mModuleInformation` are optional `TMap` fields. They are
keyed by an item class and a waste-producer module class, respectively, for
entries that feed fluid or waste-producer modules. The property reference shows
their map-key/value shapes. This resource uses neither module type, so it does
not need those fields. `mScannerTier` is unused and omitted.

## Gating an ore behind a module

`mNeededModules` makes a module mandatory. At runtime,
`AKLMMBuildableMiner::HasAllNeededModules` prevents production until every
listed attachment is installed. Every ore lists the mining head shown above,
so that entry does not gate anything.

Adding the fluid attachment turns the ore into a fluid-gated one:

```yaml
      - path: mNeededModules
        value:
          - /KAPI/Attachments/ModularMiner/Attachment_MM_MiningHead.Attachment_MM_MiningHead_C
          - /KAPI/Attachments/ModularMiner/Attachment_MM_FluidModule.Attachment_MM_FluidModule_C
```

Listing fluids only in `mFluidInfo` keeps them as optional speed boosts, like
water for Coal. Adding the fluid module to `mNeededModules` makes it required.
It also removes the ore's plain "extract \<ore\>" entry from the wiki export,
leaving only the per-fluid recipes.
