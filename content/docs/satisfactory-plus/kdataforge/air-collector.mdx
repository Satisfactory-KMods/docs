Define an Air Collector resource as a `KAPIAirCollectorData` instance in a
`type: dataasset` document. This replaces creating the asset in Unreal Editor.
See the
[full property reference](/satisfactory-plus/kapi/air-collector/) for every field.

This example mirrors Satisfactory Plus's shipped "Air Collector extract Toxic
Air via Resource Nodes" asset. `bUseHightBasesdProduction` selects one of two
mutually exclusive production models. Here it is `false`, so
`mMaxHit`/`mProductionPerHit` are active. The other model's
`mProduceItemCountMin`/`Max`/`Base` fields are omitted instead of left at their
defaults:

```yaml
# file: air-collector-toxic-air.dataasset.yml
type: dataasset
conditions: { hasMod: KAPI }
assets:
  - id: AirCollector_ToxicAirNode
    class: /Script/KAPI.KAPIAirCollectorData
    properties:
      - path: mRecipePrio
        value: 100
      - path: mRangeToScan
        value: 2500
      - path: bCheckNodes
        value: true
      - path: mTraceChannel
        value: [ObjectTypeQuery1, ObjectTypeQuery2, ObjectTypeQuery9, ObjectTypeQuery6]
      - path: mItemClass
        value: /KLib/Assets/Ressources/Raw/Gas/Desc_ToxicAir.Desc_ToxicAir_C
      - path: mProductionTime
        value: 6
      - path: bUseHightBasesdProduction
        value: false
      - path: mMaxHit
        value: 2
      - path: mProductionPerHit
        value: 6000
```

See [Adding KAPI Data Assets](/kdataforge/examples/kapi-data-assets/) for a
`type: dataasset` example of every KAPI type.
