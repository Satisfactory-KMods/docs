Satisfactory Plus rebuilds factory progression around longer production chains,
new resources, specialized machines, and rebalanced power and logistics. It is
an overhaul, not a content pack designed to drop into an established vanilla
factory.

Start a new save for clean progression. Existing SF+ saves can continue across
updates when release notes say so, but a vanilla factory should not be treated
as an SF+ migration target.

## For mod authors

SF+ uses two KMods tools for data-driven integrations:

- [KAPI](/satisfactory-plus/kapi/) is a compiled dependency. Its DataAssets
  define supported miner resources, Filtrator recipes, Air Collector resources,
  slug breeding data, and other extensible content.
- [KDataForge](/satisfactory-plus/kdataforge/) applies readable YAML patches at
  runtime. Compatibility packs can change supported DataAssets without linking
  against SF+ C++.
